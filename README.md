# RAYNE MOTORS — V2 Concept Project

A polished, responsive automotive dealership and rental web experience featuring vehicle discovery, filtering, booking interactions, and responsive design.

## Important
Rayne Motors is fictional. Inventory, prices, reviews, customers, contact details and booking results are demonstration data only.

## Run
Open `index.html` in a browser, or serve the folder with any static HTTP server.

## Included
- Responsive multi-page site
- Vehicle data/filtering/search
- Vehicle detail pages via `vehicle.html?id=...`
- Gallery filtering
- Rental request validation
- Local-storage cart
- Login/signup demo UI
- Demo testimonial carousel
- Accessible mobile navigation and cart
- Reduced-motion support

## Image note
The vehicle visuals are intentionally self-contained SVG concept placeholders so the project works without third-party image dependencies. Replace files in `assets/images/` with licensed automotive photography when desired.

## Deployment

This is a static HTML/CSS/JavaScript site and can be deployed directly to GitHub Pages, Cloudflare Pages, Netlify, or Vercel without a build step.
